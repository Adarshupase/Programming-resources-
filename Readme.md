**Books**

*Advanced programming in UNIX environment* (APUE)

by Richard Stevens

Any book from Richard stevens is a goldmine.
Probably the greatest book on Unix programming.
he is the author of TCP/IP Illustrated (vol 1,2,3), Unix network programming.

there is also a nice YouTube playlist for the concepts explained in this book for people who just wants to get core concepts and don't want to read the book.
https://youtube.com/cs631apue

*Linux programming interface* 

by Michael Kerrisk

this is just APUE but for linux

Michael Kerrisk was the maintainer of the linux man pages.

*The C programming language*

by Brian Kerninghan & Dennis Ritchie 

*Crafting Interpreters*

by Robert Nystrom

Great book, Includes code for each and every step to write your own interpreter. First part you write a tree walk interpreter in java. Second part is a Bytecode virtual machine in C.
